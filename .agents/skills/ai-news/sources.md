# AI News Sources Reference

Use these when core searches need more depth or the user asks for coverage from specific outlets.

## Official labs and companies

| Source | Best for |
|--------|----------|
| [OpenAI News](https://openai.com/news) | GPT releases, product launches, partnerships |
| [Anthropic News](https://www.anthropic.com/news) | Claude, safety, enterprise |
| [Google DeepMind Blog](https://deepmind.google/discover/blog/) | Research, Gemini, science applications |
| [Meta AI Blog](https://ai.meta.com/blog/) | Open models, Llama, research |
| [Microsoft AI Blog](https://blogs.microsoft.com/ai/) | Copilot, Azure AI, partnerships |
| [NVIDIA Blog — AI](https://blogs.nvidia.com/blog/category/deep-learning/) | Hardware, inference, ecosystem |
| [Hugging Face Blog](https://huggingface.co/blog) | Open-source models, tools, community |

## Research

| Source | Best for |
|--------|----------|
| [arXiv cs.AI / cs.LG](https://arxiv.org/list/cs.AI/recent) | New papers (verify uptake before calling "breakthrough") |
| [Papers With Code — trending](https://paperswithcode.com/) | Papers with benchmarks and code |

## Policy and safety

| Source | Best for |
|--------|----------|

## Search hints by topic

- **Model wars:** `"GPT" OR "Claude" OR "Gemini" release benchmark site:openai.com OR site:anthropic.com OR site:blog.google`
- **Open weights:** `open source LLM weights release Hugging Face`
- **AI coding:** `AI coding agent IDE Copilot Cursor Devin`
- **Chips/export controls:** `AI chip export restriction NVIDIA H100`
- **Funding:** `AI startup funding round series`
